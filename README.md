# 🚀 s42agent — Lightweight AI Agent for Sysadmins

**s42agent** — быстрый, компактный и автономный консольный ИИ-агент для системных администраторов (Linux & Windows).  
Написан на чистом Go, не требует внешних тяжелых зависимостей (типа Python/Node.js) и собирается в единый бинарный файл размером всего ~6.8 МБ.

---

## ✨ Ключевые возможности

* ⚡ **Streaming (Потоковый вывод)** — ответы модели генерируются в реальном времени символ за символом без задержек.
* 📋 **Bracketed Paste & Multiline** — комфортная вставка огромных логов и кода (`Ctrl+V`) без преждевременной отправки, ручной перенос строки по `Alt+Enter` или `Ctrl+J`.
* ❓ **Режим консультации (`?`)** — если запрос начинается с `?`, на программном уровне полностью отключаются инструменты (`tools`), модель физически не может выполнить команду и даёт только текстовый ответ/объяснение.
* 🔍 **Автоопределение контекстного окна** — автоматическое чтение лимита токенов из LM Studio (`196608`), OpenRouter, vLLM или встроенной таблицы моделей.
* 🗜️ **Умное сжатие контекста (`pruneContext`)** — при заполнении контекста (>75%) старые вызовы инструментов автоматически сжимаются, спасая от ошибки `400 Context Length Exceeded`.
* 🔒 **Встроенная безопасность** — подтверждение опасных операций (`[Y/n]`), защита от перезаписи критических путей (`/etc/shadow`, `System32`), таймаут выполнения команд (2 мин) и обрезка огромного вывода.
* 💬 **Встроенные слэш-команды** — `/help`, `/model`, `/clear`, `/tokens`, `/compact`, `/exit`.
* 💾 **Сохранение сессий** — автосохранение истории в JSON и Markdown с возможностью продолжения при перезапуске.

## 🛠️ Доступные инструменты агента (Tools)

| Инструмент | Описание | Подтверждение |
|---|---|:---:|
| `execute_cmd` | Выполнение команд в bash (Linux) или cmd.exe (Windows) с таймаутом | ⚠️ Требуется (или флаг `-A`) |
| `read_file` | Чтение файлов на диске (с автообрезкой вывода) | Автоматически |
| `write_file` | Запись и редактирование файлов (с проверкой системных путей) | ⚠️ Требуется |
| `dir_list` | Сканирование файлов и каталогов | Автоматически |
| `get_sys_env` | Получение информации о системе (диски, ОС, права root/admin) | Автоматически |
| `web_search` | Поиск в Интернете | Автоматически |
| `fetch_webpage` | Загрузка и очистка содержимого веб-страниц | Автоматически |
| `download_file` | Скачивание файлов из сети | ⚠️ Требуется |

## 🚀 Быстрый старт

### 1. Требования
* Установленный [Go (1.21+)](https://golang.org) для сборки из исходников.
* Любой OpenAI-совместимый API (LM Studio, Ollama, vLLM, OpenRouter, OpenAI, DeepSeek, LocalAI и др.).

### 2. Сборка бинарников

```bash
# Клонировать репозиторий
git clone https://github.com/nodirmail/s42agent.git
cd s42agent

# Сборка для Linux (с оптимизацией размера)
go build -ldflags="-s -w" -o agent .

# Сборка для Windows
GOOS=windows go build -ldflags="-s -w" -o agent.exe .
```

### 3. Конфигурация

Создайте файл `config.json` (или скопируйте `config.example.json`):

```json
{
  "url": "http://localhost:1234/v1",
  "key": "",
  "model": "qwen2.5-coder-7b-instruct"
}
```

Также параметры можно передавать через переменные окружения или флаги:

```bash
# Запуск с указанием параметров
./agent -url "http://127.0.0.1:1234/v1" -model "qwen2.5-coder-7b-instruct"

# Просмотр доступных моделей на сервере
./agent -url "http://127.0.0.1:1234/v1" -models

# Автоматическое подтверждение всех действий (режим администратора)
./agent -A

# Запуск с чистой сессией
./agent -clean
```

## ⌨️ Управление в интерактивном чате

| Команда / Клавиша | Описание |
|---|---|
| `Enter` | Отправить сообщение |
| `Alt + Enter` / `Ctrl + J` | Перенести строку без отправки |
| `Ctrl + V` | Безопасная вставка многострочного текста / логов (Bracketed Paste) |
| `? <текст>` | **Режим консультации**: ответ без вызова инструментов |
| `/help` | Показать справку по доступным командам |
| `/model` | Просмотреть список моделей или переключить (`/model <номер|имя>`) |
| `/tokens` | Показать текущее использование контекста и токенов |
| `/compact` | Вручную сжать старую историю вызовов инструментов |
| `/clear` / `/reset` | Очистить текущую сессию и начать заново |
| `/exit` / `/quit` | Выход |
