# 🚀 s42agent — Lightweight AI Agent for Sysadmins

[![Go Version](https://img.shields.io/badge/Go-1.22+-00ADD8?style=flat&logo=go)](https://golang.org)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Release](https://img.shields.io/github/v/release/nodirmail/s42agent?color=green)](https://github.com/nodirmail/s42agent/releases)
[![Platform](https://img.shields.io/badge/platform-Linux%20%7C%20Windows%20%7C%20macOS-blue)](https://github.com/nodirmail/s42agent/releases)

**s42agent** is a fast, standalone, and lightweight terminal-based AI agent designed for system administrators (Linux, Windows & macOS).  
Built with pure Go, it requires no heavy runtime dependencies (no Python, no Node.js) and compiles into a single static binary of only **~6.8 MB**.

---

## ✨ Key Features

* ⚡ **Streaming Response Output** — tokens stream in real-time as they are generated by the model with zero perceptual latency.
* 📋 **Bracketed Paste & Multiline Input** — paste massive logs and scripts (`Ctrl+V`) without accidental premature execution; insert newlines with `Alt+Enter` or `Ctrl+J`.
* ❓ **Consultation / Question Mode (`?`)** — prepend queries with `?` (e.g. `? why did nginx fail`) to strictly disable tools at the software protocol level, forcing the model to provide text-only advisory answers without executing commands.
* 🔍 **Auto Context Window Detection** — automatically reads the loaded context window length from LM Studio (`196608`), OpenRouter, vLLM, or model heuristics.
* 🗜️ **Smart Context Compaction (`pruneContext`)** — automatically compacts older tool execution results when context usage exceeds **75%**, preventing `400 Context Length Exceeded` errors during long sessions.
* 🔒 **Built-in Safety & Security** — explicit confirmation prompts (`[Y/n]`) for destructive actions, directory traversal safeguards (`/etc/shadow`, `System32`), command execution timeouts (2 min), and output truncation.
* 💬 **Interactive Slash Commands** — in-chat commands like `/help`, `/model`, `/clear`, `/tokens`, `/compact`, `/exit`.
* 💾 **Session Persistence** — automatic state saving to JSON and Markdown format with seamless recovery on restart.

## 🛠️ Built-in Tools

| Tool | Description | Confirmation |
|---|---|:---:|
| `execute_cmd` | Execute shell/bash/CMD commands with timeout | ⚠️ Required (or `-A` flag) |
| `read_file` | Read files on disk with output truncation protection | Automatic |
| `write_file` | Create or overwrite files with system path protection | ⚠️ Required |
| `dir_list` | Inspect directory contents and file sizes | Automatic |
| `get_sys_env` | Collect environment info (OS, kernel, disks, root/admin privileges) | Automatic |
| `web_search` | Search the web for troubleshooting guides and docs | Automatic |
| `fetch_webpage` | Download and clean web page content into readable text | Automatic |
| `download_file` | Download files/drivers directly to disk | ⚠️ Required |

## 📥 Installation & Quick Start

### 1. Download Pre-built Binaries

Download ready-to-run binaries directly from [GitHub Releases](https://github.com/nodirmail/s42agent/releases) for your OS and architecture:

* **Linux**: `s42agent-linux-amd64` / `s42agent-linux-arm64`
* **Windows**: `s42agent-windows-amd64.exe` / `s42agent-windows-arm64.exe`
* **macOS**: `s42agent-darwin-arm64` (Apple Silicon) / `s42agent-darwin-amd64` (Intel)

---

### 2. Build from Source

```bash
# Clone the repository
git clone https://github.com/nodirmail/s42agent.git
cd s42agent

# Build optimized binary for Linux
go build -ldflags="-s -w" -o agent .

# Build for Windows
GOOS=windows go build -ldflags="-s -w" -o agent.exe .

# Build for macOS (Apple Silicon)
GOOS=darwin GOARCH=arm64 go build -ldflags="-s -w" -o agent .
```

## ⚙️ Configuration

Create a `config.json` file in the application directory (or copy from `config.example.json`):

```json
{
  "url": "http://localhost:1234/v1",
  "key": "",
  "model": "qwen2.5-coder-7b-instruct"
}
```

### CLI Flags & Environment Variables

```bash
# Launch with custom API endpoint and model
./agent -url "http://127.0.0.1:1234/v1" -model "qwen2.5-coder-7b-instruct"

# List all available models on the server
./agent -url "http://127.0.0.1:1234/v1" -models

# Auto-approve all tool actions without confirmation prompts
./agent -A

# Start a fresh session, ignoring previous history
./agent -clean
```

Environment variables supported: `AI_API_URL`, `AI_API_KEY`, `AI_MODEL`.

## ⌨️ Interactive Chat Controls

| Command / Shortcut | Action |
|---|---|
| `Enter` | Submit query to agent |
| `Alt + Enter` / `Ctrl + J` | Insert a newline without submitting |
| `Ctrl + V` | Safely paste multiline logs/code (Bracketed Paste) |
| `? <query>` | **Consultation Mode**: Text-only advice (tools disabled) |
| `/help` | Show available slash commands |
| `/model` | View available models or switch model (`/model <number|name>`) |
| `/tokens` | Display token usage and context window percentage |
| `/compact` | Manually compress older tool results in context |
| `/clear` / `/reset` | Clear conversation history and start fresh |
| `/exit` / `/quit` | Exit application |

---

## 🔒 Privacy & Safety

All session history (`session.json`, `session.md`) and configuration files (`config.json`) are automatically excluded via `.gitignore` to prevent any accidental leakage of private API credentials or system logs.
