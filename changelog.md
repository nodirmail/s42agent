# SA42Agent Changelog

## 🚀 Версия v1.0.9

### 🪟 Поддержка Legacy Windows (Windows Server 2008 R2 / Win 7 / 8 / 2012)
* **Legacy-сборки без `bcryptprimitives.dll`**: добавлены отдельные бинарники `s42agent-windows-amd64-legacy.exe` и `s42agent-windows-386-legacy.exe`, собранные через тулчейн Go 1.20. Они используют совместимые системные вызовы (`RtlGenRandom` / `CryptGenRandom`) и запускаются на Windows Server 2008 R2 SP1 и Windows 7 без ошибок рантайма.
* **Автоматическое определение в `install.ps1`**: скрипт установки PowerShell автоматически проверяет версию ядра Windows NT (`[System.Environment]::OSVersion.Version.Major < 10`) и на устаревших системах бесшовно загружает совместимую legacy-сборку.
* **Флаг `-Legacy` в установщике**: возможность принудительно запросить legacy-версию при установке.

### ⚡ Флаг `-A` (Always) для полного авто-одобрения
* **Флаг `-A` при запуске**: флаг командной строки `agent -A` / `s42agent -A` для автоматического одобрения всех действий (выполнение команд, запись файлов) без интерактивных запросов подтверждения.

## 🚀 Версия v1.0.8

### 📏 Ручная настройка размера контекстного окна (`-c` / `/c`)
* **Флаг `-c` и команда `/c`**: добавлена возможность явно задавать размер контекстного окна в командной строке (например, `-c 32k` или `-c 131072`) или интерактивно в чате (`/c 32k`).
* **Гибкий парсинг форматов**: поддерживаются как прямые целочисленные значения (`131072`, `32000`), так и сокращения (`32k`, `64k`, `128k`, `1m` и др.).
* **Информативный вывод**: просмотр текущего лимита по команде `/c` и в приветственном баннере агента.

### 🌐 Приоритет языка ответов (`-l` / `/l`)
* **Флаг `-l` и команда `/l`**: добавлена возможность задавать приоритетный язык ответов по коду языка (например, `-l ru` или `-l en`, `/l ru`).
* **Поведение по умолчанию**: если приоритет не задан, агент отвечает на том языке, на котором был задан вопрос пользователя. Сброс к поведению по умолчанию выполняется командой `/l auto`.
* **Динамическое обновление**: переключение языка через `/l` мгновенно обновляет системный промпт текущей сессии.

### 💾 Запоминание параметров конфигурации
* **Автоматическое сохранение**: параметры размера контекста (`context_limit`) и приоритета языка (`language`) сохраняются в файл конфигурации (`config.json`) при указании через флаги или слэш-команды и восстанавливаются при последующих запусках.

### ⚡ Опция «A» (Always) при подтверждении действий
* **Опция `A` при подтверждении (`(y/N/A)`)**: при запросе подтверждения (`Разрешить запуск команды? (y/N/A):`) добавлен выбор `A` (или `a` / `always` / `всегда`).
* **Точечное авто-одобрение по типам действий**: выбор `A` запоминается для данного типа действий (выполнение команд, запись файлов на диск, скачивание) и автоматически положительно одобряет все последующие запросы этого типа в текущей сессии.
### 📦 Улучшения скрипта установки `install.sh`
* **Автоматическая настройка PATH**: скрипт автоматически определяет shell пользователя (`bash`, `zsh`) и добавляет `~/.local/bin` в `~/.bashrc` или `~/.zshrc`, если каталог отсутствует в `$PATH`.
* **Готовая команда применения**: установщик выводит команду в один клик (`source ~/.bashrc` или `export PATH="$HOME/.local/bin:$PATH"`) для мгновенного применения в текущей консоли.
* **Доступность из корня репозитория**: скрипты установки `install.sh` и `install.ps1` добавлены в корень репозитория для поддержки коротких ссылок установки.

## 🚀 Версия v1.0.6

### ⚙️ Интерактивный мастер первого запуска
* **Запрос API Key при первом запуске**: при отсутствии конфигурации агент теперь запрашивает API Key (с возможностью нажать Enter для локальных/безключевых серверов вроде LM Studio, Ollama, vLLM).
* **Интерактивный выбор модели из списка**: после подключения к серверу агент автоматически выводит пронумерованный список доступных моделей с возможностью выбрать модель по номеру или нажать Enter для выбора первой модели по умолчанию.
* **Автоматическая нормализация URL**: корректная обработка и автоматическое добавление схемы `http://`, если пользователь ввёл адрес без протокола.

### 📦 Скрипты быстрой однострочной установки (One-Line Install)
* **Linux & macOS**: добавлен скрипт `install/install.sh`, автоматически определяющий архитектуру (`amd64` / `arm64`) и операционную систему (`linux` / `darwin`), загружающий свежий релиз и настраивающий симлинки `s42agent` и `agent`.
* **Windows (PowerShell)**: добавлен скрипт `install/install.ps1` с полной совместимостью с PowerShell 5.1+, поддержкой TLS 1.2+ и автоматическим добавлением в пользовательский `PATH`.
* **Документация**: добавлены готовые команды установки через `curl` и `irm` в `README.md` и каталог `install/`.

## 🚀 Версия v1.0.5

### 👁️ Инструмент `view_image` и автономный визуальный анализ
* **Встроенный инструмент `view_image`**: теперь модель может самостоятельно вызывать функцию `view_image(path)` для любого найденного файла изображения на диске (например, после сканирования папки скриншотов через `dir_list`).
* **Автоматическое перенаправление `read_file`**: если модель пытается вызвать `read_file` для файла с расширением `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.bmp`, вызов автоматически направляется в `view_image`.
* **Инжекция изображения в зрительное восприятие**: при вызове `view_image` агент считывает файл, формирует `image_url` блок и автоматически добавляет его в следующий шаг диалога. Модель получает реальное изображение и сразу анализирует интерфейс/скриншот.
* **Обновление системных промптов (Windows / Linux / macOS)**: модель теперь изначально проинформирована о наличии мультимодальных возможностей и инструмента `view_image`, что исключает ошибочные ответы о невозможности работы с изображениями.

## 🚀 Версия v1.0.4

### 🖼️ Поддержка мультимодальности (анализ изображений и скриншотов)
* **Автоматическое прикрепление изображений**: при указании пути к файлу изображения (`.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.bmp`), включая пути Windows Snipping Tool (`ScreenClip\{...}.png`) и drag-and-drop путей, файл автоматически загружается, кодируется в Base64 Data URL и отправляется в мультимодальную модель в формате OpenAI API `image_url`.
* **Слэш-команда `/image <путь> [вопрос]`**: добавлена явная команда для прикрепления изображений.
* **Защита контекста от бинарного мусора**: функция `read_file` теперь распознаёт бинарные файлы и изображения и возвращает информативное сообщение вместо отправки десятков тысяч токенов нечитаемых бинарных байт в модель.
* **Мультимодальная структура сообщений**: полная поддержка как текстового, так и блочного контента (`[]ContentPart`), прозрачная обратная совместимость с сессиями `session.json`, сжатием контекста и генерацией отчёта `session.md`.

### ⚡ Исправление работы `Ctrl+C` (управление прерываниями)
* **Выход по `Ctrl+C` на пустой строке**: если поле ввода пустое, нажатие `Ctrl+C` корректно завершает работу агента. Если в строке был текст, `Ctrl+C` сбрасывает набранный ввод без выхода из программы.
* **Прерывание генерации ИИ**: при нажатии `Ctrl+C` во время генерации ответа модели (`callAPIStream`) сетевой запрос плавно отменяется через `context.Canceled`, в консоль выводится `[Прервано пользователем (Ctrl+C)]`, и управление возвращается к приглашению `User >>> ` без падения или зависания программы.
* **Прерывание системных команд**: выполнение системных команд через `executeCmd` теперь также перехватывает сигнал прерывания и останавливает процесс.

## 🚀 Версия v1.0.3

### 🛠️ Исправление перерисовки терминала и определение ширины консоли на Windows
* **Корректный расчет ширины консоли на Windows**: дескриптор `os.Stdout.Fd()` используется для запроса `GetConsoleScreenBufferInfo`, что исключает ошибку `INVALID_HANDLE` при вызове на stdin.
* **Устранение дублирования строк**: корректное позиционирование курсора при наборе и редактировании длинного текста, превышающего ширину окна терминала.
* **Пакетная обработка вставки (Batch Rune Draining)**: мгновенная вставка больших фрагментов текста через буфер обмена без посимвольного мерцания и скролла.

## 🚀 Версия v1.0.2

### 🎯 Платформенная специализация системных промптов (Windows / Linux / macOS)
* **Разделение платформенного кода**:
  * `sys_windows.go` (`//go:build windows`) — глубокая интеграция с Windows (`%TEMP%`, `sfc`, `dism`, `powershell`, правила для драйверов и вендоров).
  * `sys_linux.go` (`//go:build linux`) — интеграция с Linux (`systemctl`, `journalctl`, `/tmp`, защита критических путей `/etc/shadow`, `/boot`).
  * `sys_darwin.go` (`//go:build darwin`) — поддержка macOS (`launchctl`, `system_profiler`, `diskutil`, `defaults`, `brew`, учет ограничений SIP).
* **Многоязычность и следование языку пользователя**:
  * Системные промпты стандартизированы на английском языке для максимальной точности работы LLM и содержат директиву ответа на языке запроса пользователя (`"Always respond concisely, to the point, and in the language used by the user."`).
* **Точное вшивание в бинарники**:
  * Каждый бинарный файл при компиляции получает строго свои системные инструкции, системное имя и набор инструментов.

## 🛠️ Что внедрено:

### 1. ❓ Режим консультации / вопросов (префикс `?`)
* Если запрос начинается с символа `?` (например, `? почему упал nginx`), агент переключается в режим **чистого ответа/консультации**:
  * На уровне протокола API полностью **отключается передача списка инструментов (`tools: nil`)**.
  * Модель физически не может вызвать ни одну системную команду или инструмент.
  * Ответ выводится только текстом.

### 2. ⚡ Streaming (Потоковый вывод ответа)
* Модель отвечает в реальном времени (`callAPIStream`), выводя слова сразу по мере генерации без пауз и ожидания полного ответа.
* Полная поддержка вызовов инструментов и fallback при недоступности стриминга.

### 3. 🛡️ Защита от зависаний (Таймауты команд)
* В `sys_linux.go` и `sys_windows.go` для `execute_cmd` добавлен таймаут **2 минуты** (`context.WithTimeout`). Зависшие команды больше не блокируют процесс.

### 4. ✂️ Защита памяти и контекста (`truncateOutput`)
* Для `execute_cmd`, `readFile` (лимит 48 КБ) и `dirList` (макс. 150 элементов) добавлена автоматическая обрезка огромного вывода.

### 5. 🔒 Усиленная безопасность путей
* Нормализация путей через `filepath.Clean` / `filepath.ToSlash`.
* Блокировка записи в системные каталоги (`/etc/shadow`, `/etc/passwd`, `/boot` в Linux, `System32`/`SysWOW64` в Windows).

### 6. 🗜️ Умное сжатие контекста (`pruneContext`)
* Автоматическое сжатие старых результатов вызовов инструментов при заполнении контекста предотвращает ошибки переполнения `400 Context Length Exceeded`.

### 7. 💬 Встроенные слэш-команды в чате
* `? <вопрос>` — режим консультации (без инструментов).
* `/help` — справка по командам.
* `/clear` или `/reset` — мгновенная очистка сессии и старт с чистого листа.
* `/model` — просмотр списка моделей или переключение (`/model <имя|номер>`).
* `/compact` — ручное сжатие истории инструментов.
* `/tokens` или `/stats` — статистика использования контекста и токенов.
* `/exit` — выход.

### 8. 🎨 ANSI-подсветка интерфейса
* Запросы пользователя: зеленый цвет `User >>> `.
* Ответы ИИ: фиолетовый `ИИ >>> `.
* Статусы и предупреждения: желтый `[БЕЗОПАСНОСТЬ]` и голубой `[Система]`.

### 9. ⌨️ Полноценный строковый редактор и навигация по стрелкам
* **Навигация стрелками**:
  * `←` / `→` (и `Ctrl+B` / `Ctrl+F`) — посимвольное перемещение курсора по набранному тексту.
  * `↑` / `↓` (и `Ctrl+P` / `Ctrl+N`) — переход между строками в многострочном вводе или навигация по истории команд (`inputHistory`) на первой/однострочной позиции.
  * `Home` / `End` (и `Ctrl+A` / `Ctrl+E`) — мгновенный переход в начало/конец текущей строки.
  * `Ctrl+←` / `Alt+←` (и `Alt+b`), `Ctrl+→` / `Alt+→` (и `Alt+f`) — перемещение по словам (с поддержкой русского и английского языков).
* **Редактирование текста в любой позиции**:
  * Вставка символов в текущую позицию курсора.
  * `Backspace` (`\b`, `\x7f`) — удаление символа перед курсором.
  * `Delete` (`\x1b[3~`, `Ctrl+D` при непустом вводе) — удаление символа под курсором.
  * `Ctrl+W` / `Alt+Backspace` — удаление слова слева от курсора.
  * `Ctrl+K` — удаление от курсора до конца строки.
  * `Ctrl+U` — удаление от курсора до начала строки.
  * `Ctrl+L` — очистка экрана и перерисовка ввода.
* **Многострочный ввод и вставка**:
  * Сохранена полная поддержка переноса строк через `Alt+Enter`, `Shift+Enter`, `Ctrl+Enter`, `Ctrl+J`.
  * Безопасная многострочная вставка (Bracketed Paste Mode).

### 10. 🔄 Встроенная система самообновления (GitHub Releases)
* **Асинхронная проверка обновлений**: при запуске агент проверяет свежий релиз на GitHub и выводит уведомление при наличии новой версии.
* **Команда `/update` и флаг `./agent -update`**:
  * Автоматическое определение текущей ОС и архитектуры (`linux/amd64`, `linux/arm64`, `windows/amd64`, `windows/arm64`, `darwin/amd64`, `darwin/arm64`).
  * Скачивание готового скомпилированного бинарника напрямую из GitHub Releases с отображением прогресса.
  * Безопасная замена исполняемого файла на лету (включая Windows с ротацией `.old`).
* **Команда `/version` и флаг `./agent -version`**: отображение текущей версии и платформы.
